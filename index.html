Editor

A full-featured editor.
No browser required.

Write with the full formatting toolkit — headings, tables, code blocks, links, and lists. Drag images from Finder directly into the document and Quill uploads them to your media library in one step.

  • Bold, italic, headings H1–H6, tables, inline and block code
  • Drag images from Finder to upload and insert in one step
  • Inline image resizing with drag handles and dimension fields
  • Full post settings — categories, tags, slug, excerpt, scheduling

Media Library

Your media library,
right there.

Browse your full WordPress media library without opening the admin. A thumbnail grid with a metadata panel — copy URLs, open in browser, or delete files without ever leaving Quill.

  • Thumbnail grid of your entire WordPress media library
  • Metadata panel — filename, dimensions, upload date, source URL
  • Right-click to copy URL, copy as Markdown, open in browser, or delete
  • Upload new files with ⌘N, refresh with ⌘R

Offline Writing

Write offline.
Publish when you're ready.

Local drafts live entirely on your Mac in a SQLite database. Write without a connection, autosave every 30 seconds, and publish whenever you're ready. Quill detects server-side changes before you overwrite anything.

  • Local drafts stored in SQLite — no internet required to write
  • Autosave every 30 seconds while you write
  • Unsaved changes restored automatically on next launch
  • Conflict detection if the post was edited elsewhere
